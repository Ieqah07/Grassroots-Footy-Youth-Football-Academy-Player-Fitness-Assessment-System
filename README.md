GrassrootsFooty

About the Project

GrassrootsFooty is a web-based football club management system designed for primary school football clubs involving children aged 10–12 years old.

The system provides a centralised platform to help manage football club activities, player information, training sessions, attendance, and fitness records.

It aims to simplify club administration, support coaches in monitoring players' progress, and improve information accessibility for parents and guardians.

Project Objectives

The main objectives of GrassrootsFooty are to:

- Digitalise football club management and administrative activities.
- Simplify player registration and information management.
- Help coaches organise and manage training sessions.
- Record and monitor player attendance.
- Maintain player fitness records and track fitness progress.
- Improve communication and information accessibility for parents and guardians.
- Encourage children's physical fitness through organised football activities.

Target Users

GrassrootsFooty consists of five main user roles:

- Administrator: Manages system users, player records, and overall club information.
- Coach: Manages training sessions, attendance, and player fitness records.
- Assistant Coach: Assists coaches with training activities and player-related records.
- Parent/Guardian: Views relevant information about their registered child and club activities.
- Public: Accesses publicly available information about the football club.

Main System Features

The system includes the following features:

- User authentication and role-based access.
- Player registration and management.
- Training session management.
- Player attendance tracking.
- Player fitness record management.
- Parent/guardian access to relevant player information.
- Public information about the football club.

Technologies Used

The project uses the following technologies:

- HTML: Structures the web pages.
- CSS: Designs and styles the user interface.
- JavaScript: Implements client-side interactivity and validation.
- PHP: Handles server-side processing and system functionality.
- MySQL: Stores and manages system data.
- Apache: Provides the local web server.
- XAMPP: Provides the local development environment.

Project Scope

GrassrootsFooty focuses on managing the administrative and operational activities of a primary school football club.

The system covers player information, training sessions, attendance, and physical fitness records.

Fitness activities may include:

- 30-metre sprint.
- Zigzag cone dribbling.
- Other football-related fitness activities.

The system supports coaches in recording and monitoring players' fitness progress rather than replacing professional fitness assessments.

Project Structure

The project files are organised into the following folders and files:

- images/ – Stores images and other resources.
- css/ – Contains stylesheets for the user interface.
- js/ – Contains JavaScript files.
- index.html – Main entry page of the website.
- README.md – Provides project information and documentation.

Development Environment

The system is developed using Visual Studio Code as the code editor and XAMPP as the local development environment.

GitHub is used for source code management and collaboration among project members.
